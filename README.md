## 搬瓦工到底会不会自动扣费？先搞清楚这件事

很多人把两个概念混在一起：**自动扣费**和**自动续费**，这是两回事。

自动扣费：系统直接从你绑定的信用卡或 PayPal 扣钱。搬瓦工**不做这件事**。官方原文明确写着"We never charge your payment method automatically"。他们甚至不存储用户的支付信息，技术上就做不到自动扣费。

自动续费：账单生成后，如果账户余额充足，系统自动从账户余额中扣除续费金额，完成续费。这个是可以做到的。

所以你不用担心某天突然发现信用卡被划了一笔。不会的。搬瓦工所有付款都需要用户主动发起——除非你事先把钱充进账户余额，让系统代劳。

## 续费开关 Renewal ON/OFF 是什么意思？

搬瓦工后台的 VPS 列表里，每台机器旁边都有一个 **Renewal: ON** 或 **Renewal: OFF** 的标识。

很多新人以为 ON 代表"自动扣费开启了"，其实不是。

**Renewal: ON** 的意思是：到期时系统会生成续费账单并发邮件通知你。你还是需要自己去付款，或者账户余额充足时自动扣余额。

**Renewal: OFF** 的意思是：系统不会生成续费账单，到期后 VPS 直接终止，没有任何通知，也不能再恢复。

一般情况下，建议保持 ON 状态。即便你不想续费了，不付账单就行，账单 7 天后自动失效。主动关掉 Renewal 反而容易出问题——万一后悔了，需要在到期前联系找到 restore 入口重新开启，过了到期时间就彻底没机会了。

## 如何取消续费？如何恢复续费？

**取消续费操作：**

登录后台 → Services → My Services → 找到对应 VPS → 点击 Manage → 找到 Manage renewal → 点击 Renewal Invoices 按钮，将状态切换为 OFF → 点击 Save changes 保存

**恢复续费操作（必须在到期前完成）：**

同样路径进入 Manage renewal 页面，将 Renewal Invoices 切换回 ON，保存即可。或者在 Services → My Services 页面找到该 VPS，点击旁边的 restore 按钮。

注意：恢复续费**必须在 VPS 到期前操作**。一旦到期，账单没生成，VPS 就直接没了，数据不可恢复。

另外，也可以通过 Request Cancellation 入口处理，但那个功能本质是取消服务而非取消续费，效果更彻底——VPS 到期当天直接终止，且不退款。大多数情况下不建议走这条路。

## 修改续费周期要注意什么？

搬瓦工支持在后台修改续费周期，比如从月付改成季付、年付。但有几条规则：

- **只能从短周期改为长周期**，不能反向操作（年付不能改成月付）
- **价格会按当前官方售价重新计算**，不再保留老购买价格
- 如果你早期以低价买入（比如 $19.99/年），修改周期可能导致续费价格大幅上涨，不建议随意改

**修改路径**：Services → My Services → Manage → Change billing cycle → 选择新周期 → 保存

## 搬瓦工自动续费常见问题 FAQ

**Q：搬瓦工会自动从我的支付宝扣钱吗？**

不会。官方明确表示不存储用户支付信息，技术上无法主动扣款。唯一的"自动"扣款是从你事先充值的账户余额中扣除。

**Q：快到期了但还没收到续费邮件，正常吗？**

如果到期时间还没到，那是正常的——续费账单会在到期前 7 天才生成。如果已经过了到期时间还没收到，先查邮件垃圾箱，再直接登录后台查看未付款账单。

**Q：续费优惠码还能继续用吗？**

能，但有前提：首购时使用的优惠码会在续费时自动沿用。首购时没用优惠码，续费时不能再补加。目前可以尝试的优惠码是 BWHCGLUKKB，购买时在结算页的 Promotional Code 栏填入即可。

**Q：账户余额充值了但到期时没有自动续费，怎么回事？**

检查两点：一是 Renewal 是否为 ON 状态；二是账户余额是否足够支付续费金额。两个条件都满足才会触发自动续费。

**Q：VPS 已经到期被暂停了，还能续费恢复吗？**

暂停后只要续费账单还存在，付款后可以恢复。但如果账单已经过期被系统删除，VPS 和数据就彻底没了，只能重新购买新套餐。
